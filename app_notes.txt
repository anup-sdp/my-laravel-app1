In modern Laravel applications, Tailwind CSS is processed by Vite.
for tailwind classes (fixed tailwind warning in welcome.blade.php):
npm install
public/build/manifest.json (or public/hot during dev) created
the @vite branch takes over,
use: @vite(['resources/css/app.css', 'resources/js/app.js']) in head of blade file,
in app.css use: @import 'tailwindcss';

run app:
start mysql server(eg. from xampp)  <------
npm run dev (keep running in terminal, vite dev server) / npm run build <-----
php artisan serve <-----

my mysql db setup process:
in xampp controll panel: Start Apache and MySQL
at http://localhost/phpmyadmin/
areate database my_laravel_app1 with Collation: utf8mb4_unicode_ci, dont create tables manually

in .env file:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3307
DB_DATABASE=my_laravel_app1
DB_USERNAME=root
DB_PASSWORD=

run:
php artisan config:clear
php artisan cache:clear

php artisan make:model Post -mcr
it creates files:
app/Models/Post.php
app/Http/Controllers/PostController.php
and a new migration file at database/migrations/
in the migration file in up functions add needed fields for class Post

now run: php artisan migrate
it creates posts(+user) table in mysql db

in routes/web.php add:
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\PostController;
Route::resource('posts', PostController::class); // gives all CRUD routes

write codes in web.php, Post.php, PostController.php, 2026_08_29_050415_create_posts_table.php

now see routes are created: php artisan route:list

no user routes yet, run :
php artisan make:model User -mcr   (...similar to post)
or (model already exists): php artisan make:controller UserController --resource
